# Portofolio Shifan Windraya Prassasti 🌐

Website portofolio interaktif berbasis web untuk **Shifan Windraya Prassasti**, mahasiswa Teknologi Rekayasa Internet (Internet Engineering Technology) Sekolah Vokasi Universitas Gadjah Mada (UGM).

## 🚀 Fitur Website
- **Hero & Profil Profesional**: Fokus pada bidang Computer Networking, Wireless Systems, dan Telecommunications.
- **Matrix Keahlian & Multi-Vendor**: Cisco, MikroTik, Huawei, Wireshark, GNS3, Linux, Python, ESP32 IoT.
- **Katalog Proyek Interaktif**: Filter dinamis (Jaringan, Nirkabel & Telekomunikasi, IoT & Server).
- **Showcase Sertifikasi**: Sertifikasi Kompetensi MTCNA, Cisco Networking Academy, Huawei ICT Academy, serta Pelatihan/Bootcamp OmahTI.
- **Modern Dark & Glassmorphism UI**: Desain responsif bertema dark/cyber modern.

## 🛠️ Teknologi yang Digunakan
- **HTML5 & Vanilla JavaScript**
- **Tailwind CSS** (via CDN)
- **Lucide Icons**
- **GitHub Pages** (Hosting)

## 📌 Catatan GitHub Pages
Repositori ini saat ini dibuat dengan visibilitas **Private**. Jika Anda ingin website ini dapat diakses secara publik di internet (misalnya via `https://shifanwindra.github.io`), Anda dapat mengubah repositori menjadi **Public** kapan saja di tab **Settings > Danger Zone > Change repository visibility**.
